# Evaluator Guide

This page provides a quick path for reviewing the repository.

1. Read the project overview and current verification statement in [README.md](../README.md).
2. Review the problem, objectives and design summary in [project-report.md](project-report.md).
3. Inspect the source implementation in [src/main.cpp](../src/main.cpp).
4. Review target and dependencies in [platformio.ini](../platformio.ini).
5. Review architecture, interface notes and safety boundaries in [architecture.md](architecture.md), [wiring.md](wiring.md) and [safety.md](safety.md).
6. Review research references and technical choices in [technical-research.md](technical-research.md) and [design-decisions.md](design-decisions.md).
7. Inspect the hosted build and test evidence through the GitHub Actions badge and workflow history.
8. Review the traceability matrix and limitations before interpreting the results.

## Important scope statement
The project is presented as a repository-based firmware and design submission. CI compilation and sample-data tests were performed. Physical hardware operation, mains installation, calibration and live MQTT delivery are not claimed.
