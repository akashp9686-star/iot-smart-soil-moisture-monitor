# Electrical and Build Safety — Project 03

- This is a low-voltage educational prototype; use a regulated 3.3V supply suitable for ESP-01 Wi-Fi current peaks.
- Connect all low-voltage grounds together as required by the module interface.
- Use a logic-level converter between 5V Uno TX and 3.3V ESP-01 RX. Never drive ESP-01 RX directly from a 5V Uno output.
- Check ESP-01 pin labels and orientation before applying power; module pinouts vary by board.
- Keep water and wet soil away from exposed electronics. Place the sensor probe in soil while keeping controller, breadboard and connections dry.
- Disconnect power before changing wiring.
